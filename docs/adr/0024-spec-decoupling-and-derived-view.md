# ADR 0024: Spec decoupling — single normative authority and the derived view

- Status: accepted
- Date: 2026-08-26

## Context

The normative v1 specification lived in `docs/protocol-v1.md`: written around the reference
implementation's vocabulary (Elixir tagged tuples as the data model, the frozen façade listed
as the contract), deferring the chain/archive byte definitions to ADR 0004, citing repository
paths, and missing the sections external reviewers require (Security Considerations, Privacy
Considerations, IANA Considerations, worked examples, terminology/overview). The external
migration risk was semantic drift: rewriting prose for a language-neutral audience while
silently changing a bound, a closed set, or a requirement statement.

## Decision

1. **One normative authority: `spec/bap-v1.md`.** The complete v1 wire profile — including the
   byte formats folded normative from ADR 0004 — lives in a single kramdown-rfc-conventioned
   document, language-neutral, repository-path-free, with the Elixir bindings and the frozen
   façade moved to an informative appendix. ADR 0004 gains a supersession note pointing at the
   spec; it remains the decision record for why the formats are shaped as they are.
2. **The migration is certified, not trusted.** The spec's normative facts are extracted from
   ten closed `<!-- facts:key -->` anchor regions by `spec/tools/extract_facts.exs`; the
   pre-swap extraction is frozen byte-for-byte in `spec/facts/baseline-v1.json`; the
   spec-facts gate (`mix spec.facts`, in `mix quality`) proves extraction == baseline (EMPTY
   delta) plus the live-truth rules (implementation bounds dump, corpus closed-set unions,
   requirement-map id/statement/count/revision reconciliation, vendor-neutrality via the ADR
   0023 canary sweep, anchor completeness, RFC-2119 keyword census, and the framing oracle
   re-parsing real corpus archive bytes). A mutation battery (`spec_facts.mutations`) proves
   the gate's own red-capability.
3. **`docs/protocol-v1.md` becomes a derived view.** It is generated by
   `spec/tools/render_derived.exs` (`mix spec.render`, in `mix quality`): the spec's bytes
   minus the kramdown front matter, plain-markdown citations, and a generation footer naming
   the authority and revision. Hand edits are gate-red. The view ships in the package for
   reader continuity; the spec ships too.
4. **Same-major document relocation is a governance change class (ADR 0022 amendment).** The
   durable-identifier policy's normative-document-path enumeration now accepts the spec path
   alongside the derived view's; moving or renaming a normative document within a contract
   major follows the same accepted-ADR discipline as any other normative change.
5. **Toolchain provenance** (appendix A of this decision, recorded below): kramdown-rfc 1.7.40
   (rubygems.org, pinned by version and gem SHA-256 in the CI render job; renders the spec to
   xml2rfc v3 — verified locally and in CI), the `cddl` ruby gem 0.12.14 (rubygems.org, pinned
   in the CI coherence job; executed locally at authoring), and the repo's own bounded JSON
   decoder for all machine-read documents (no new package dependencies). Fallback posture:
   the gates that gate (spec-facts, examples, render) are pure Elixir/Node on repo tooling;
   the CI render/coherence jobs are verification, not authoring dependencies — their absence
   degrades external-format assurance, never the drift gates.
6. **Venue posture.** The spec is an I-D-shaped readiness artifact: no IETF stream or IPR
   title-block fields, no submission claim in any tracked document. External filing follows
   the recorded external preconditions and is out of scope here.

## Consequences

- Any change to a normative fact — in the spec, the implementation bounds, the corpus closed
  sets, the requirement map, or the registries — is stopped by a named gate rule until every
  pole is reconciled deliberately.
- The derived view can never again silently diverge from the spec; reader-facing documentation
  cites the spec (or the view, labeled as generated).
- The program's certification artifact is the frozen baseline plus the empty-delta gate run —
  review evidence, not review replacement: the one-time full comparative read of the new spec
  against the old authority covers what hashes cannot (reworded normative prose, algorithm
  narrative, considerations adequacy), with written disposition notes.
